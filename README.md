# Fynn-Micheals HR Solutions

Website for Fynn-Micheals HR Solutions, an HR consultancy in Ghana. *People. Performance. Progress.*

Plain HTML, CSS and JavaScript. The pages are generated by a small Python script so the
header, footer and SEO tags stay the same on every page.

## Editing

- Page content lives in `src/*.html` (one file per page).
- Contact details, SEO titles/descriptions and the domain are at the top of `build.py`.
- Styling is in `styles.css`; menu, form and scroll effects in `script.js`.

After editing, rebuild the pages and commit the result:

    python build.py
