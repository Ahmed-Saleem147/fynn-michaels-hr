# Fynn-Michaels HR Solutions

Website for Fynn-Michaels HR Solutions (HR consulting). Plain HTML, CSS and JavaScript, no build step.

- `index.html` — page content
- `styles.css` — styling (black, white and gold)
- `script.js` — mobile menu, scroll effects, contact form
- `favicon.svg` — browser-tab icon

## Preview locally

Open `index.html` in a browser, or run:

    python -m http.server 5190

and visit http://localhost:5190.
